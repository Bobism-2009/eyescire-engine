2D & 3D game engine.

Download Docs

A clear way to make games

Everything you need to author, play, and export — without a maze of panels.

  • Dedicated 2D & 3D

    Same scene file for flat layout and world space. Flip the viewport to 3D when the project needs depth, lights, and fog.

  • Focused editor

    Hierarchy, viewport, and inspector. Multi-select, gizmos, and Play that runs through the real game camera.

  • Script in Nexa

    Engine and games share one language. Attach scripts in the editor; the runtime loads them with your scene.

  • Ship on Windows

    Export a player build with your project packed for distribution — including optional content protection.

  • Physics & particles

    Box2D under the hood, plus emitters, weather, and day/night controls for living environments.

  • Open source

    MIT-style contribution welcome. The editor, runtime, and host layer live in one repository.

Editor

See the game you are making

Author entities in 2D layout or orbit a 3D view. Selection outlines, move tools, and the game view share one picture so what you edit is what Play shows.

Runtime

One engine under Edit and Play

Scenes, scripts, physics, and input go through the same native layer. Export packs that stack for the player instead of a separate pipeline.
